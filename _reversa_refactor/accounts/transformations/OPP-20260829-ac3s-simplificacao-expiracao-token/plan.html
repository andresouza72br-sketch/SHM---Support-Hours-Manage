1. Lógica Atual vs Lógica Proposta

Lógica Atual (backend/apps/accounts/views.py):

if timezone.now() > token_obj.expira_em:
    return Response(
        {"detail": "Este link de login expirou (validade de 15 minutos). Solicite um novo link."},
        status=status.HTTP_410_GONE,
    )

Lógica Proposta:

if token_obj.esta_expirado():
    return Response(
        {"detail": "Este link de login expirou (validade de 15 minutos). Solicite um novo link."},
        status=status.HTTP_410_GONE,
    )

2. Tabela de Casos de Equivalência

Cenário Estado do Token Resultado Atual Resultado Proposto Equivalência
Token dentro da validade (ex: criado há 5 min) expira_em = now + 10m False (continua fluxo) False (continua fluxo) ✅ Idêntico
Token expirado (ex: criado há 20 min) expira_em = now - 5m True (HTTP 410 Gone) True (HTTP 410 Gone) ✅ Idêntico
Token no limite exato de expiração expira_em = now False False ✅ Idêntico
