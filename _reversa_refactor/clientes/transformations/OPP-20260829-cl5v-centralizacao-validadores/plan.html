OPP-20260829-cl5v: Centralização e Padronização dos Validadores de CPF e CNPJ

Contexto: clientes | Alvos: backend/apps/clientes/models.py, backend/apps/clientes/serializers.py

1. Inconsistência Identificada

Validação Ausente no Model Clean: As funções de validação matemática de dígitos verificadores de CPF e CNPJ estavam definidas em models.py mas não eram invocadas no método Cliente.clean(), dependendo exclusivamente da validação manual em ClienteSerializer.validate().

2. Simplificação Proposta

Model-Level Validation: Integrar a validação matemática de validar_cnpj e validar_cpf diretamente no método Cliente.clean() do Django, garantindo integridade de dados uniforme em todas as operações (API, Admin, ORM e migrações).

3. Comparação de Código

# ANTES (em Cliente.clean):
if not self.cnpj:
    raise ValidationError({"cnpj": "CNPJ é obrigatório para Pessoa Jurídica."})
# (sem validação matemática dos dígitos)

# DEPOIS:
if not self.cnpj:
    raise ValidationError({"cnpj": "CNPJ é obrigatório para Pessoa Jurídica."})
if not validar_cnpj(self.cnpj):
    raise ValidationError({"cnpj": "O CNPJ informado é inválido."})
