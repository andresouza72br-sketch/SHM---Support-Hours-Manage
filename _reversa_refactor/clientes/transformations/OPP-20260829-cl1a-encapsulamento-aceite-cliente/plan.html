Reversa Restructure (Atomicidade & Transição de Estado)

OPP-20260829-cl1a: Encapsulamento de Aceite Cadastral em ClienteService.formalizar_aceite

Contexto: clientes | Alvos: backend/apps/clientes/views.py, backend/apps/clientes/services.py

1. Code Smell Identificado

Fat View & Falta de Atomicidade: O método AceiteClienteView.post executa mutações em ClienteAceiteLink, ativação cadastral de Cliente (status, dados de aprovação e verificação de e-mail) e criação de notificações em lote diretamente no handler HTTP sem transação atômica.

2. Refatoração Proposta

Extract Method / Service Layer: Criar o método ClienteService.formalizar_aceite() decorado com @transaction.atomic em apps/clientes/services.py.

A View AceiteClienteView atua estritamente como despachante HTTP, retornando as mesmas respostas e status codes (200, 404, 409, 410).

3. Comparação de Camadas

# ANTES (em AceiteClienteView.post):
link.usado = True
link.save(...)
cliente.status = StatusCliente.ATIVO
cliente.email_verificado = True
cliente.save(...)
Notification.objects.bulk_create(...)

# DEPOIS:
cliente, link, status_code, err_msg = ClienteService.formalizar_aceite(token=token, ip=ip, user_agent=ua)

4. Rede de Segurança e Preservação

Coberto por test_clientes_e_usuarios.py (15 testes verdes no baseline).
