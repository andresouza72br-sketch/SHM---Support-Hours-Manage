Contexto: notificacoes | Alvo: backend/apps/notificacoes/services.py

Diagnóstico da Complexidade Acidental

Código repetido 3 vezes nos métodos notificar_novo_pedido, notificar_novo_comentario e notificar_evento_ciclo para resolver strings de remetente e buscar destinatários no banco.

Prova de Equivalência

Entrada (Autor / Cliente / Ciclo) Comportamento Anterior Comportamento Simplificado Equivalência
Autor Empresa, Cliente com Fantasia origem = "Empresa", autor_nome formatado _obter_info_autor_e_origem -> ("Nome", "Empresa") 🟢 Idêntico
Autor Cliente, Cliente com Razão Social origem = cliente.razao_social _obter_info_autor_e_origem -> ("Nome", "Razão") 🟢 Idêntico
Coleta de Destinatários do Pedido Set com Cliente + Empresa - Autor _obter_destinatarios_envolvidos 🟢 Idêntico
Coleta com Operador do Ciclo Set com Cliente + Empresa + Operador - Autor _obter_destinatarios_envolvidos(..., ciclo=ciclo) 🟢 Idêntico
