Reversa Restructure (Separação de Camadas)

OPP-20260828-e2qx: Encapsulamento de Regras de Consulta em ContratoQuerySet

Contexto: saldo | Alvos: backend/apps/saldo/views.py, backend/apps/contratos/models.py

1. Code Smell Identificado

Vazamento de Regras de Consulta na View: Os endpoints contratos_elegiveis e contratos_devedores em SaldoViewSet constroem queries ORM detalhadas com operadores Q, limites de data e status contratuais diretamente na camada HTTP/DRF.

2. Refatoração Proposta

Move Method / Encapsulate Query: Definir ContratoQuerySet no módulo de contratos com os métodos semânticos elegiveis_para_migracao() e devedores().

A View passa a consumir diretamente a API de domínio do modelo.

3. Comparação Antes vs Depois

# ANTES (em SaldoViewSet):
qs = Contrato.objects.filter(cliente_id=cliente_id, saldo__gt=0).filter(
    models.Q(status__in=[StatusContrato.EXPIRADO, StatusContrato.CONCLUIDO])
    | models.Q(data_termino__lt=hoje)
)

# DEPOIS:
qs = Contrato.objects.elegiveis_para_migracao(cliente_id=cliente_id, destino_id=destino_id)

4. Rede de Segurança e Preservação
