### Diagnóstico

`ContratoService.gerar_numero(ano=None)`:
1. `Contrato.objects.filter(numero__startswith=prefixo).values_list("numero", flat=True)` traz todos os números do ano para memória.
2. Faz loop Python com regex para extrair `max_seq`.
3. Executa `while Contrato.objects.filter(numero=candidato).exists(): seq += 1` fazendo requisições SQL adicionais se houver gaps.

### Solução Proposta

Obter o maior número diretamente via ordenação SQL (`order_by("-numero").first()`) ou filtro ordenado na base de dados, gerando o sequencial seguinte em O(1) sem carregar listas inteiras na memória.
