### Oportunidade

A View `PedidoViewSet.perform_create` realiza resolução de cliente, geração de protocolo e despacho de evento de notificação acoplados diretamente ao framework HTTP:
```python
protocolo = PedidoService.gerar_protocolo()
user = self.request.user
contrato = serializer.validated_data.get("contrato")
cliente = user.cliente if (hasattr(user, "is_cliente") and user.is_cliente and user.cliente) else (contrato.cliente if contrato else None)
pedido = serializer.save(protocolo=protocolo, criado_por=user, cliente=cliente)
```

### Proposta de Desacoplamento

Criar `PedidoService.criar_pedido(dados, usuario)` encapsulando a transação atômica, resolução de cliente e despacho de evento, fazendo a View atuar apenas como adaptadora.
